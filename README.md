# JosiahChristian.github.io

Personal portfolio site for Josiah Christian.

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

Create a public repository named exactly `JosiahChristian.github.io`, push these files to `main`, and enable GitHub Pages from the repository root if it does not activate automatically.

The site is intentionally framework-free, responsive, accessibility-aware, and organized software-first with deeper research discoverable below the primary engineering surface.

## Validation

```bash
npm test
```

The dependency-free Node.js suite verifies navigation targets, canonical
metadata, current GitHub ownership, and launch/repository links for both live
applications. GitHub Actions runs it on every push and pull request.
